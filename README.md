# Excel Data Analytics Dashboard Project

## Project Overview
This project demonstrates an interactive Excel dashboard developed to analyze sales and business performance across multiple countries and products.

The dashboard provides insights into revenue, cost, profit, units sold, product performance, and monthly trends.

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Formulas
- Data Analysis
- Interactive Dashboard Visualization

## Dataset Description
The dataset contains 700 records with the following columns:

- Country
- Product
- Units Sold
- Revenue
- Cost
- Profit
- Date

## Key Analysis
- Country-wise profit analysis
- Product-wise sales and profitability
- Monthly units sold analysis
- Revenue and cost performance
- Business performance comparison across markets

## Project Files
- `Excel_Dashboard.xlsx` – Excel workbook containing the dataset, analysis, and dashboards.
- `Screenshots/dashboard.png` – Dashboard preview.

## Key Learnings
- Data organization and analysis using Excel.
- Creating PivotTables and PivotCharts.
- Developing business performance dashboards.
- Extracting actionable insights from sales data.
